# Performance and duplication audit, 2026-09-24

Three read-only passes over `src/engine`, `src/ui` + `src/state`, and `pipeline/`.
Nothing here is applied. Line numbers are from commit 1b65afe plus the gesture fix.

## Engine (`src/engine`)

### Performance, by impact

1. **Idle sway runs forever, on every tier.** `index.js:886-889`, `idle.js:63-77`. PLAN §8
   says zero frames while idle and ambient motion on High only; `allowed()` never checks
   quality and `step()` never stops. Four seconds after the last touch a low-tier phone
   renders at 30 fps indefinitely, DOM label updates included. Fix: gate on
   `quality.name === 'high'`, stop after ~2 periods.
2. **Every state entry / tier swap converts heights to half floats on the main thread.**
   `textures.js:22-27` (from `terrain.js:183`, `block.js:122`, `world.js:24`): a per-texel
   JS loop, millions of iterations, during the block-lift tween. Fix: pipeline emits f16
   bits; else a worker.
3. **Re-entering a state re-downloads and re-decodes its package.** `index.js:780-804`,
   `exitState` disposes everything. Fix: cache 1-2 decoded packs by slug.
4. **`project()` allocates per marker per frame.** `camera-math.js:112-117`,
   `picking.js:109-115`, used by `points.update`, `labels.update`, `marks.nearest`. `basis()`
   does 4 trig calls + 5 allocations per call; thousands per frame during a pan. Fix:
   `makeProjector(cam, viewport)` computed once per frame, writing into a reused array.
5. **Up to three terrain ray-marches per pointer frame.** `index.js:971-985`: `lineAt`,
   `pickArea` and hover each call `pick()`. Fix: pick once, pass the hit down; hit-test
   markers against the screen positions the last render already computed.
6. **Hover near the unnamed river network scans every segment.** `lines.js:256-275`: the
   bbox test is per record and that record's box covers the country. Fix: a coarse
   uniform grid of segment indices built once in `linesGeometry`.
7. **`applyCamera` rewrites every line material and does a linear find each frame.**
   `index.js:556` → `lines.js:313-316`, `172-185`. Fix: compute `uSelectedIdx` on
   selection change; `setView` writes only resolution/zoom, only when changed.
8. **`invalidate()` creates a MediaQueryList every call.** `index.js:88` → `tween.js:8`.
   Fix: one module-level `matchMedia`.
9. **Marker ground height recomputed per vertex.** `mark.vert.glsl:55-75`: 7 texture
   fetches + 5 `pow` per vertex for a per-instance value. Fix: per-instance `iCorners`
   (vec4) + `iId` attributes, refreshed on tier swap.
10. **Search index rebuild re-scans every line vertex on month change.**
    `index.js:228-242`, `lines.js:101-106`, `282-292`. Fix: cache `reaches` per
    `(layerId, stateId)`.
11. **Label collision is O(n²) per frame.** `points.js:181`, `labels.js:118`. Fix: 64 px
    screen-grid buckets.
12. **Label measurement forces a layout per label.** `labels.js:102` → `measure` 64-84:
    write text, read `offsetWidth`, write transform, ×72. Fix: separate measure pass.
13. **Prism lookup texture rebuilt on every layer toggle.** `index.js:323-334`. Fix: guard
    on id like `choroId`.
14. **Area selection scans the whole raster.** `index.js:518-533`. Fix: boxes computed
    once in `areaIds()`.
15. **First tier's rasters kept after the fine tier loads.** `index.js:1044`: only `.ids`
    is read. Fix: `tierIds = { ids: first.ids }`.
16. **Per-frame `new Set(active)` and join keys in `render()` / `marks.setView`.**
    `index.js:114,122-123`, `marks.js:176-177`. While markers pop in, the full DOM path
    runs per frame instead of `draw()` only.

### Duplication

17. **Shader chunks.** `lift()` ×5 (+ `liftKm` in JS), `luv()` ×4 (+ inline `line.frag:23`),
    bilinear `groundAt` in `line.vert` and `mark.vert`, prism lift ×2, id decode ×6.
    Fix: `shaders/common.glsl?raw` prepended to each shader.
18. **Item-visibility rule ×4.** `points.js:153-162`, `points.js:215-216`,
    `marks.js:192-201`, `index.js:212-216`. Fix: one exported `itemVisible(item, ctx)`.
19. **Inside `index.js`:** hand-built `store.set('item', …)` ×8 → `openItem()`; the
    load/fill/`.catch/.finally` block ×2; "points → marks → tour.refresh" ×3;
    `world?.setCurve({…})` ×5 and the relief tween ×2 → `setExag(v)`; area-item `.find`
    ×3 → Maps by id / area_id; `manifest.layers.find` ×3 → `typeOf` Map;
    `fineIdsTexture` re-implements `data.js`'s `versioned()` with a hard-coded `/data/`.
20. **Across modules:** `DataTexture` LUT setup ×3 in `choropleth.js` = `textures.js`
    `finish()`; pack → textures ×3 (`terrain`, `block`, `world`); category map + `#b4552e`
    fallback in `marks.js` and `points.js`; token/bead sizes declared twice;
    `markerScale` = `labelScale`; three `layers` subscribers and four `level` subscribers
    doing overlapping work (`loadActiveLayers`, `loadDetail`, `tour.refresh`,
    `publishIndex`).

## UI and state (`src/ui`, `src/state`, `src/i18n`, `src/main.js`)

### Performance, by impact

1. **Relief slider rebuilds the whole catalogue on every input tick.** `shell.js:267-270`
   → `store.subscribe('relief', renderLayerList)` → `replaceChildren()` at `:240`, so the
   slider under the pointer is destroyed and recreated per tick; `url.js:163` also does
   a `replaceState` per tick (Safari throttles ~100/30 s). Fix: update the relief row in
   place; debounce the URL write like the camera one.
2. **Store treats every new array as a change → fan-out.** `store.js:5-12` compares by
   identity; engine publishes fresh arrays for `regional`, `index`, `tour.stops`. One
   layer toggle runs `renderLayers`, `renderSheet` (strip twice), `renderList`,
   `renderTour`, `renderSteps`, a URL write. `openPlateById` (`shell.js:630-641`) sets 8
   slices → ~4 `renderSheet`, 2 `renderLayerList`, 3+ `renderStrip`, ~8 URL builds. Fix:
   one-level-deep array compare in `shallowEqual`; shell marks dirty and renders once
   per frame.
3. **`formatNumber` builds an `Intl.NumberFormat` per call**, including from `renderScale`
   on every camera frame. `i18n/index.js:48-50`. Fix: one formatter per language.
4. **Camera subscriber writes DOM every frame** whether or not anything changed.
   `shell.js:498-506`. Fix: diff `turned` and the scale label first.
5. **Hover forces layout 2-3× per mouse move.** `renderHover` (`shell.js:1066-1079`)
   writes then reads `getBoundingClientRect`, subscribed to `hover`, `hoverLine` and
   `pointer`; `gestures.js` `local()` reads the rect twice per move (both `onMove` and
   `onHover` bound). Fix: cache the canvas rect on viewport change; coalesce to one rAF.
6. **Sheet drag forces layout per move.** `sheet.js:59-66` reads `offsetHeight` after
   writing `transform`; `setSnap` → `updatePadding` (`shell.js:1144-1151`) reads again.
   Fix: measure once in `onDown`.
7. **Catalogue search box steals focus on every re-render.** `shell.js:1012`. Fix: focus
   only when `view` becomes `'layers'`.
8. **Search re-sorts all units and scans the whole index per keystroke**, no debounce.
   `shell.js:592-612`, `:532`. Fix: sort once per `regions`/lang; stop at 40; Map by id.
9. **`layerMark` mints new clip ids every render** so SVG marks cannot be cached.
   `legend.js:47,77`.
10. **`buildUrl` re-parses `location.search` per pass-through key.** `url.js:72-75`.
11. **`attachGestures` cleanup misses `contextmenu` and the `gesture*` listeners.**
    `gestures.js:365-370`. No leak today (never detached).

### Duplication

1. **Plate preset applied twice, differently.** `shell.js:635-637`, `:647-649` vs
   `url.js:94-104`, `:118-135`, `:214-217`; the relief rule differs between them.
   "Find plate by id" ×5, default-layers expression ×4 (incl. `engine/index.js:1037`).
   Fix: `plateById`, `defaultLayers`, `presetFor(store, plateId)` in `src/state/`.
2. **"Back one level" ×3:** `shell.js:106-113`, `:486-491`, `main.js:129-135`.
3. **External link / source line ×5:** `sourceNote`, `renderFacts`, `renderItem`,
   `renderCredits`.
4. `factRow` = `renderFacts`'s `row`; blurb paragraph ×2.
5. `layerRow` ≈ `baseRow` (90%).
6. `BASE_MARKS.relief` = `GLYPHS.mountain` byte for byte; wave path repeated; `glyph()` in
   `legend.js` = `glyphSvg` in `glyphs.js`.
7. Rounded-square clip markup ×2 in `legend.js`.
8. `unit.replace('{n}', formatNumber(v))` ×3.
9. `aria-label` + `title` pair ×5; `sheetSnap` set ×7 with the peek→half check ×2.
10. Item reset object ×3 (`shell.js:536`, `:895`, `main.js:42`).
11. `gestures.js`: turn/pan maths in `glide` and `onMove`; two-finger start ×2;
    `deltaAngle` = `wrapYaw` in radians.
12. `credits.js` `field()` = `pick()` with a language argument.
13. `style.css`: button reset ×5, switch-on rules ×2, hover/focus rules ×4.

## Pipeline (`pipeline/`)

Measured: `06_states.py` is ~208 s of every `npm run data`; ~192 s of it is
`raster.bounded_distance`. The rest of the pipeline is about a minute.

### Performance, by impact

1. **`bounded_distance` (`lib/raster.py:108-128`) does one full-array pass per offset in
   a disc**: r=29 (bleed) and r=43 (coast) in `06_states.py:143,155` → ~2,600 and ~5,800
   passes per state crop. Fix: separable bounded distance transform (row pass then
   min over dy of dy²+g²), ~2r+1 passes; map k² back to float32 through a LUT of the
   same `np.float32(np.hypot(dy, dx))` values so bytes stay identical. Also serves
   `01:146`, `02:295`, `03:114`. Line 143 needs only a threshold, so a dilation would do.
2. **`build.py` reruns every step every time.** Fix: input-hash stamps in
   `pipeline/tmp/`; always run `05_manifest.py`.
3. **`lib/lines.py:291-339` `corridor`: 23.9 s for 21 rail items**: re-projects all 14,272
   chains per item, then a triple Python loop. Fix: project once per layer, bbox
   prefilter, numpy distance test (same float64 arithmetic → same bytes).
4. `04_layers.py:839` calls `load_source` again (2.3 s): pass the index from `build_lines`.
5. GeoJSON/shapefile sources read twice (`lib/lines.py:164`, `:137`): 100 MB `nh.geojson`
   parsed twice. Route both through `features()`.
6. `lib/pmtiles.py:281-340`: 6.4 s pure-Python decode of rivers per build. Disk-cache the
   decoded features keyed on archive size/mtime + zoom + decoder version.
7. `lib/districts.py:179-232` `shared_edges`: Python loop over 1.77M points. Numpy
   `np.unique` over a structured view, re-sorted by first occurrence.
8. `01_boundaries.py:271-272` computes `unit_stats` and the hull per tier, keeps the last.
9. `lib/lines.py:393-395` `project` runs `lcc.forward` twice per part.
10. Minor: `_nearest_node` re-projects nodes per waypoint; `04:373-376` full-raster
    compare per area (use the `bincount` from `shade_areas`); `04:863` re-reads
    `states.json`; `04:1492` re-parses the file it just wrote.

### Duplication

1. `03_world.py` and `06_states.py` import `02_dem.py` by path via `importlib`. Move
   `load_mosaic`, `box_down`, `sample_bilinear`, `ambient_occlusion` and constants to
   `lib/terrain.py`, with: Mercator pixel (×3 + `fetch.tile_range`), shade block (×3),
   land/ocean quantisation (×2), signed edge field (×2), pixel-centre meshgrid (×2).
2. Scene↔pixel conversions inlined instead of `grid` (`02:187,224`; `01:176-211`;
   `districts.py:135`); region-at-point ×3 in `04`.
3. "Rasterise named lon/lat polygons, biggest first" ×4.
4. Shoelace area ×3 (`shapefile.signed_area`, `contour.shoelace`, `topo.ring_area`).
5. Split-polyline-by-mask loops ×3 (`_clip`, `_split_inside`, `08:on_board`).
6. 4-connected dilation ×2 (`04:raster_dilate`, `lines._inside_mask`).
7. Item validation copied across three validators in `04` plus `01` and `07`;
   `bilingual` ×3, `BLURB_MAX` ×3. → `lib/content.py`.
8. Compact `json.dump(...)` ×10 → `write_json`; per-state detail write ×2; run flattening
   ×4 (keep Python `round`, `np.round` differs in the last digit).
9. Steps 5 and 7 each list/parse `public/data/layers/*.json` (5 does it twice).
10. `lib/shapefile.py` two record readers differing only in the type tuple.
11. Dead: `lines.noded`, `lines.bridge`, `shapefile.read_lines`.
